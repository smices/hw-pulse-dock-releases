# PulseDock releases

This public repository distributes signed PulseDock macOS update assets only. Application source is maintained separately in a private repository.

Download the documentation package from Releases for the first installation. Apple Silicon and macOS 12 or later are required. Future versions can be checked from the App's Check for Updates menu. The signed appcast and App-only ZIP are used by Sparkle.

The local App uses ad-hoc signing and is not notarized. See the included installation and update guides for current acceptance limits. License notices are included in the App and distribution packages. No signing private keys or user configuration are distributed.
